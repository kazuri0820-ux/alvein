# サッカー監督シミュレーション ― 構想メモ

個人で遊ぶ、監督・GM 視点のサッカーマネジメントゲーム。
実在選手を使い、ひとつのクラブを育てて勝ち上がっていく。

- **プロジェクト仮称**: `Gaffer`（＝英語で「監督」のスラング。名前は後で変更可）
- **決定済みの方向性**
  - ゲームタイプ: **監督・GM マネジメント型**（試合は自動シミュレート＋実況で観戦）
  - スコープ: **1チーム運営に集中**（他チームは結果だけ自動反映）
  - 選手データ: **実在スター選手の初期データセットを同梱**（後から編集・追加も可）

---

## 1. コンセプト

プレイヤーは1つのクラブの監督兼GMになる。選手を編成し、フォーメーションと戦術を決め、
試合ボタンを押すと確率シミュレーションで試合が進行し、テキスト実況とスタッツで観戦する。
勝敗はリーグ順位に反映され、シーズンを重ねてタイトルを狙う。

操作は「編成する・戦術を決める・試合を観る」の3つが中心。反射神経は不要で、
データと采配で勝つ、じっくり型のゲーム。

## 2. コアループ

```
[ダッシュボード]
   │  次節を確認
   ▼
[編成] スタメン11人 + 控えを選ぶ
   │
   ▼
[戦術] フォーメーション / プレー強度 / ラインの高さ を設定
   │
   ▼
[試合] 自動シミュレート → テキスト実況 + スタッツ + スコア
   │
   ▼
[結果反映] 自チームの勝点・順位を更新、他チームの結果も自動生成
   │
   ▼
（次節へ戻る）… 全日程消化 → [シーズン終了] 順位確定・タイトル判定 → 次シーズン
```

## 4. データモデル（案）

```jsonc
// 選手
{
  "id": "p001",
  "name": "選手名",
  "pos": "ST",              // GK / DF / MF / FW を細分（CB, LB, CM, ST など）
  "age": 27,
  "overall": 88,           // 総合値（能力値から算出 or 直接指定）
  "stats": {               // 6要素（FIFA風）
    "pac": 90, "sho": 92, "pas": 80,
    "dri": 88, "def": 40, "phy": 78
  },
  "condition": 100,        // コンディション/疲労 0-100
  "form": 0                // 好不調 -3〜+3（試合ごとに変動）
}

// チーム
{ "id": "t01", "name": "クラブ名", "players": ["p001", ...], "isPlayer": true }

// 試合
{ "home": "t01", "away": "t05", "score": [2,1], "events": [ ... ] }

// セーブ全体（localStorage に保存）
{ "season": 2026, "round": 5, "teams": [...], "table": [...], "playerTeamId": "t01" }
```

## 5. 試合シミュレーションのロジック（案）

能力値と戦術から、局面ごとの発生確率を計算して乱数で試合を進める。

1. **チーム力の算出**: スタメンの能力値をポジション別に集計 → `攻撃力 / 中盤支配力 / 守備力` を出す。戦術補正（攻撃的/守備的、プレス強度、ラインの高さ）を掛ける。
2. **ポゼッション配分**: 両チームの中盤支配力の比でボール保持率を決定。
3. **チャンス生成**: 試合を n 個の「局面」に分割。各局面で保持側の攻撃力 vs 相手守備力でチャンス発生を判定。
4. **シュート → ゴール**: チャンスが出たら決定力（sho/dri）と相手GK・守備でゴール判定。
5. **イベント記録**: ゴール・決定機・警告などをテキスト実況ログに追加。
6. **乱数と好不調**: 各選手の `form` とコンディションを補正に加え、番狂わせが起きる余地を残す。

出力: 最終スコア、得点者、ポゼッション、シュート数、枠内数などのスタッツ。

## 6. 実在選手の初期データセット

- **方針**: まずは主要リーグのスター選手を中心に、能力値付きで同梱（個人利用前提）。
- **規模の目安（MVP）**: 1リーグ・**12〜16クラブ**、各クラブ **18〜23人** 程度。
  - 最初は自チーム＋対戦相手数チームだけ実データを厚くし、残りは簡易生成でも可。
- **データ更新**: JSON として持ち、選手エディタ（v3）や JSON インポート/エクスポート（後日）で更新可能に。
- **法的メモ**: 実在選手名・能力値の利用は **個人での非公開利用に限定**。配布・公開する場合は名前を差し替えるなどの配慮が必要。

## 7. 技術方針

- **形式**: ブラウザで動く単一ページ。サーバー不要、オフライン可、`localStorage` にセーブ。
- **既存リポジトリとの共存**: 現在の `index.html`（別ゲーム「アルヴェイン王国記」）は残し、
  サッカーゲームは **別ファイル/別ディレクトリ**（例: `soccer/index.html`）に置く。
  ※どこに配置するかは実装開始時に確認する。
- **構成**: 依存ライブラリなしの Vanilla JS を基本。データ量が増えたら `src/` 分割＋簡易ビルドも検討。
