## 運用ルール（トリガー用）

- 1回のセッションは1タスクに集中し、動くものを積み上げる（大きすぎるなら分割）。
- 変更後は可能な範囲で node による純ロジックのテストを行う（DOM非依存部分）。
- ロードマップが全て完了したら、バグ修正・磨き込みを行うか、やることが無ければ
  `list_triggers` でこの自律トリガーを見つけて `update_trigger` で disable にする。
- 実在選手データは個人利用の範囲。公開/配布はしない。
