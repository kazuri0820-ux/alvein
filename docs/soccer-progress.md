## 運用ルール（トリガー / ループ用） ★重要

**毎イテレーションで必ず次のサイクルを回す（無限にブラッシュアップし続ける）:**

1. 「次にやること」から未完了タスクを**1つ**選び実装する（大きすぎるなら分割して1つ）。
2. 可能な範囲で node による純ロジックのテスト（DOM非依存部分）を行い、壊れていないか確認。
3. **必ず新しいタスクを1つ以上「次にやること」に追加する** — バグ修正・UX改善・新機能・
   データ拡充・見た目の磨き込み等、何でもよい。バックログを枯らさず常に改善余地を残す。
4. `soccer/index.html` は**常に単一ファイルで完全に遊べるブラッシュアップ版**を保つ
   （壊れた状態でpushしない）。変更ログにバージョンを追記。
5. コミットして `claude/soccer-simulation-game-concept-qhky3e` へ push。

- 既存 `index.html`（別ゲーム）は触らない。PRは作らない。
