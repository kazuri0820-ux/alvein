### RPGコア（最優先）
1. [x] **選手XP・レベル・成長システム（基盤）**: 実装済。自クラブ先発が試合でXP獲得（出場+得点+アシスト+勝敗+CS）→レベルアップで能力値が伸びる（ポジション別成長）。スカッドにLv/OVR/XPバー、ダッシュボードに平均Lv、結果画面にレベルアップ表示。セーブ永続・シーズン跨ぎ。

3. [x] **育成/トレーニング画面**: 実装済。`育成`タブ。1節あたりTP=3を消費し、6メニュー（シュート/パス/守備/フィジカル/スピード/ドリブル）で選手を鍛える→狙った能力+1・経験値+70。TPは次節で回復。能力は99上限、育成でレベル/特性も開花。
4. [x] **監督（プレイヤー）のレベル・采配パーク**: 実装済。`監督`タブ。試合結果でXP獲得（勝+50/分+25/敗+10、得点×5）→レベルアップでパークポイント。5種の采配パーク（攻撃指導/中盤掌握/守備規律=チーム力+1/Lv、育成環境=練習XP+15%/Lv、モチベーター=試合XP+10%/Lv、各max5）。ダッシュボード/結果画面に監督Lv・未使用ポイント通知。
5. [x] **ポテンシャル/成長タイプ**: 実装済。各選手にOVR上限(ポテンシャル)と成長型(早熟/標準/晩成)を id ハッシュで決定的に付与。能力はポテンシャル到達で成長停止（青天井防止）。成長型でXP必要量が変化（早熟0.9/晩成1.12、晩成は上限+3）。スカッドにPOT列・成長型・MAX表示、育成時に上限到達を通知。
6. [x] **クエスト/シーズン目標**: 実装済。`クエスト`タブ。5種のシーズン目標（7勝/通算25得点/CS4回/選手Lv8/リーグ優勝）を進捗バー表示、達成で監督XP・パークポイント報酬。毎シーズン更新。試合/育成/シーズン終了時に判定・通知。★これでRPGコア#1〜#6が全て完成。
