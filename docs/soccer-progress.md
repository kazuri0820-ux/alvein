## 次にやること（RPG監督型・優先度順）📋

各回のループで**1つ**選んで実装 → 動作確認 → 台帳更新 → 新タスク追加 → コミット＆プッシュ。
RPGの成長レイヤーを優先的に積む。

### RPGコア（最優先）
1. [x] **選手XP・レベル・成長システム（基盤）**: 実装済。自クラブ先発が試合でXP獲得（出場+得点+アシスト+勝敗+CS）→レベルアップで能力値が伸びる（ポジション別成長）。スカッドにLv/OVR/XPバー、ダッシュボードに平均Lv、結果画面にレベルアップ表示。セーブ永続・シーズン跨ぎ。
2. [ ] **選手スキル/特殊能力（アビリティ）**: 決定力↑/キラーパス/鉄壁/スピードスター等の特性。レベルや育成で解放し、試合シミュに補正を与える。
3. [ ] **育成/トレーニング画面**: 試合間に練習メニューを割当て、狙った能力にXP/成長を寄せる。体力/ポイント消費。
4. [ ] **監督（プレイヤー）のレベル・采配パーク**: 監督XP/レベル。ハーフタイムブースト・育成効率↑・移籍予算↑等のパーク解放。
5. [ ] **ポテンシャル/成長タイプ**: 選手ごとに伸びしろ（上限）と成長曲線（早熟/晩成）を設定。若手の育成に意味を持たせる。
6. [ ] **クエスト/シーズン目標**: 「リーグ優勝」「若手を Lv20 に」等。達成で報酬（XP・ポイント）。

### マネジメント基盤（RPGと相互作用）
7. [ ] **選手詳細画面**: プロフィール・Lv/XP・成績（得点/アシスト/出場）・スキル一覧。
8. [ ] **選手コンディション/疲労**: 連戦で体力低下、休養・ローテーション。負傷イベント。（育成体力とも連動）
9. [ ] **移籍市場**: シーズン間で選手売買・フリー獲得。予算/資金の概念。
10. [ ] **選手出場数・平均点(マッチレーティング)の記録**: 詳細/ランキングに反映。XP計算にも活用。
11. [ ] **AIクラブの成長**: 対戦相手もシーズンごとに緩やかに成長し、難易度を保つ。
12. [ ] **カップ戦（トーナメント）**: リーグと並行するノックアウト大会。
13. [ ] **簡易2Dピッチ表示**: フォーメーション図・試合の簡易ビジュアル化。
14. [ ] **選手エディタ / JSONインポート・エクスポート**: データ入出力と手動調整。
15. [ ] **複数セーブスロット**: 複数キャリアの管理。
16. [ ] **UIの磨き込み**: レスポンシブ・アニメーション・効果音（任意）。
17. [ ] **控え/途中出場のXPとローテーション動機**: 現状は先発のみ成長。控えにも少量XP、疲労と絡めてローテーションに意味を持たせる。
18. [ ] **レベルアップ演出の強化**: 獲得XPの内訳（出場/得点/勝利…）表示、上昇した能力値の明示、簡単なアニメーション。
